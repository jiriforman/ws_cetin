# Narcos Workshop – AI in Project Management (template)

Anonymized template of a gamified, multi-team workshop app: phases with timers, team pages, rankings, an AI tool arsenal, a big-screen dashboard and an AI-played supplier **Negotiation Room**.

> This repo contains **no workshop content and no credentials**. Phases, teams, tools and negotiation suppliers are created in `/admin` after setup.

**Start here → [ONBOARDING.md](./ONBOARDING.md)**

| Stack | |
|---|---|
| Frontend | Vite · React · TypeScript · shadcn-ui · Tailwind |
| Backend | Supabase (Postgres, Storage, Realtime, Edge Functions / Deno) |
| AI | Anthropic API (default) or Lovable AI gateway |
